# 자산 목표

**목표 나이**와 **목표 금액**을 정하고, 내 자산 합계가 목표 대비 어디쯤인지 보여 주는 개인용 앱입니다.
매주 한 번 기록을 남기면 실제 속도와 목표 경로를 그래프로 비교합니다.
증권사 앱 화면을 **캡처해서 넣으면 금액을 읽어** 채워 줍니다.

아이폰 홈 화면에 아이콘으로 설치되는 PWA라서 App Store 심사, 애플 개발자 계정,
맥북·Xcode 없이 바로 쓸 수 있습니다. 설치 후에는 비행기 모드에서도 열립니다.

---

## 1. 화면

### 홈
- 현재 순자산 (자산 합계 − 부채 합계)
- **목표**: `55세(2045년)까지 30억` 형태. 달성률 막대와 남은 금액
- 네 개의 요약
  | 항목 | 뜻 |
  |---|---|
  | 목표까지 | 남은 금액과 남은 햇수 |
  | 연간 필요 증가액 | 목표를 맞추려면 해마다 얼마씩 늘어야 하는지 (월 환산도 함께) |
  | 최근 증가 속도 | 최근 기록들로 계산한 실제 속도 (주당 / 연 환산) |
  | 이 속도면 도달 | 지금 속도가 유지될 때 목표 금액에 닿는 해와 나이 |
- **목표 대비 내 자산** 그래프 — `목표까지` / `최근 1년` 전환
  - `목표까지`: 목표 연도까지의 전체 경로
  - `최근 1년`: 주간 점이 목표 선 위/아래 어디에 찍히는지 확대해서 보기
- 이번 주 기록 여부 배너

### 자산
- 항목마다 **이름 + 금액**만 입력합니다. 수익률·시나리오 같은 건 없습니다.
- 자산과 부채를 따로 추가하고, 합계와 순자산이 위에 뜹니다.
- 각 항목의 **📷 버튼**으로 캡처에서 금액을 읽어 채울 수 있습니다.
- **캡처로 한 번에 입력** — 여러 장을 골라 합계를 한 항목에 넣습니다.

### 기록
- 이번 주에 기록이 없으면 배너에 **기록하기** 버튼이 뜹니다.
- 기록에는 날짜, 총자산, 총부채, 메모, 첨부 캡처가 들어갑니다.
- 목록에 순자산과 **전 주 대비 증감**이 함께 표시됩니다.
- 같은 날짜로 다시 저장하면 덮어씁니다.

### 설정 (우측 상단 톱니)
테마 · 백업 내보내기/가져오기 · 앱 버전과 강제 업데이트 · 전체 초기화

## 2. 캡처로 금액 넣기

증권사·은행 앱 화면을 캡처해 두었다가 앱에서 불러오면, 화면 속 금액을 찾아 **버튼으로 보여 줍니다.**
맞는 숫자를 눌러 고르면 끝입니다.

1. 자산 탭에서 항목의 **📷** 또는 **캡처로 한 번에 입력**을 누릅니다
2. **사진 선택** → 캡처 이미지를 고릅니다 (여러 장 가능)
3. 찾아낸 숫자가 버튼으로 나옵니다. 맞는 것을 눌러 선택합니다
   - 가장 큰 숫자가 대개 총액이라 자동으로 하나 선택해 둡니다
   - 여러 장을 넣으면 **선택한 숫자들의 합계**가 들어갑니다
4. **적용**

동작 방식과 한계:
- 화면에서 **천 단위 콤마가 있는 숫자**(`6,912,778`)만 후보로 삼습니다. 주식 수량이나 계좌번호 같은 잡음을 걸러내기 위해서입니다.
- 흰 글씨·색 배경 헤더까지 읽으려고 원본과 반전본을 각각 한 번씩 처리합니다. 한 장에 1~2초 걸립니다.
- **처음 한 번만** 인식 엔진(약 10MB)을 내려받습니다. 이후에는 캐시에 남아 오프라인에서도 동작합니다.
- 숫자를 잘못 읽을 수 있으므로 **반드시 눈으로 확인하고 고르는** 구조입니다. 자동으로 확정하지 않습니다.
- 금액은 **원 단위로 읽어 만원 단위로 바꿔** 넣습니다. (6,912,778원 → 691만원)

## 3. 데이터가 사라지지 않게

데이터는 아이폰 안에만 저장되고 어디로도 전송되지 않습니다. 사라지지 않도록 세 가지를 겁니다.

1. **IndexedDB + localStorage 이중 저장** — 저장할 때마다 두 곳에 쓰고, 열 때 더 최신인 쪽을 씁니다.
   한쪽이 비워져도 다른 쪽에서 복구됩니다.
2. **영구 저장 요청** (`navigator.storage.persist()`) — 브라우저에게 이 데이터를 정리 대상에서 빼 달라고 요청합니다.
   설정 화면에서 허용 여부를 확인할 수 있습니다.
3. **백업 파일** — 설정 → 내보내기로 파일 앱에 저장해 둘 수 있습니다.

> **홈 화면에 추가해서 쓰세요.** Safari 탭으로만 쓰면 iOS가 7일 이상 방문이 없을 때
> 저장소를 정리할 수 있습니다. 홈 화면 앱으로 실행하면 이 대상에서 빠지고,
> 영구 저장 요청도 승인될 확률이 높습니다.
>
> 그래도 기기를 바꾸거나 Safari 데이터를 직접 지우면 사라지니, 가끔 백업을 내보내 두시는 편이 안전합니다.

## 4. 아이폰에 설치하기

앱으로 설치하려면 파일이 **https 주소**로 열려야 합니다. (파일을 직접 열어서는 홈 화면에 추가할 수 없습니다)

### GitHub Pages
저장소가 이미 Public이고 Pages가 켜져 있다면 주소는 다음과 같습니다.

**`https://swj7124-netizen.github.io/WJ-1/`**

Settings → Pages 의 Branch 가 앱 파일이 있는 브랜치(`main` 또는 `claude/personal-asset-simulator-49ten9`)인지 확인하세요.

### 홈 화면에 추가
1. **Safari**로 주소를 엽니다 (Chrome 앱에서는 설치되지 않습니다)
2. 하단 가운데 **공유 버튼**
3. **홈 화면에 추가**
4. 홈 화면 아이콘으로 실행하면 주소창 없는 전체화면 앱으로 열립니다

## 5. 업데이트가 반영되지 않을 때

앱은 열 때마다 서버를 확인하고, 새 버전이 있으면 받아온 뒤 자동으로 새로고침합니다.
그래도 화면이 그대로라면 아이폰에 남은 캐시 때문입니다.

1. **설정 → 앱 업데이트 → 최신 버전 강제로 받아오기** (입력한 데이터는 지워지지 않습니다)
2. 그래도 안 되면 홈 화면 아이콘을 길게 눌러 앱을 삭제한 뒤, Safari로 다시 열어 홈 화면에 추가
3. 설정 화면의 **설치된 버전**이 저장소의 최신 버전과 같은지 확인

**배포할 때는 버전을 올려 주세요.** 세 곳을 같은 값으로 맞춰야 캐시가 확실히 갱신됩니다.

| 파일 | 위치 |
|---|---|
| `index.html` | `styles.css?v=` / `chart.js?v=` / `ocr.js?v=` / `app.js?v=` |
| `sw.js` | 맨 위 `var VERSION` |
| `assets/app.js` | 맨 위 `var VERSION` |

## 6. 파일 구성

```
index.html                 화면 구조
assets/styles.css          디자인 시스템 (다크/라이트)
assets/app.js              상태 관리 · 목표 계산 · 렌더링
assets/chart.js            의존성 없는 SVG 차트
assets/ocr.js              캡처에서 금액 읽기 (tesseract.js 를 필요할 때만 로드)
vendor/tesseract/          인식 엔진 (약 10MB, 처음 사용할 때만 내려받음)
manifest.webmanifest       PWA 설치 정보
sw.js                      서비스워커 (오프라인 캐시)
icons/                     앱 아이콘
```

서버 통신은 없습니다. 인식도 전부 아이폰 안에서 처리되며, 캡처 이미지는 밖으로 나가지 않습니다.

### 데이터 형식

```jsonc
{
  "v": 2,
  "settings": { "birthYear": "1990", "theme": "auto", "chartRange": "goal" },
  "goal":     { "age": 55, "amount": 300000 },        // 만원
  "items":    [ { "id": "…", "kind": "asset", "name": "아파트", "amount": 80000 } ],
  "records":  [ { "id": "…", "date": "2026-08-10", "assets": 92035,
                  "debts": 30000, "net": 62035, "note": "", "shots": ["…"] } ]
}
```

첨부 캡처는 IndexedDB의 별도 저장소에 들어가고, 기록에는 그 id만 남습니다.

### 이전 버전에서 넘어올 때

수익률·시뮬레이션 기능이 있던 v1 데이터는 앱을 처음 열 때 자동으로 옮겨집니다.
자산·부채 항목은 이름과 금액만 남고, 기록은 그대로 이어집니다.
